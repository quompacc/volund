# Changelog-Archiv

[Zur aktuellen Änderungsübersicht](../../CHANGELOG.md).

## [0.38.3] - 2026-09-03

### Fixed

- Derive worker health expiry from each component's declared interval so the
  hourly import cleanup no longer reports a false blocked state after five
  minutes.
- Keep library administration inside the available tablet width.

### Changed

- The Gitea RustSec gate now pins the current `cargo-audit` 0.22.2 patch
  release.

- Split Administration into six focused, keyboard-operable areas for account,
  operations, storage, automation, access, and settings.
- Collapse long job histories and setting domains by default, and add visible
  labels to administration forms.

## [0.38.2] - 2026-09-03

### Fixed

- Keep Administration forms, lists, settings, model history, dashboard
  statistics, and navigation inside the declared tablet and mobile viewports.
- Return keyboard focus to the originating file-menu control when Escape closes
  the model-file context menu.

### Changed

- Correct the repository front page to report the current product version.
- Align the backup service's structured-log version with the shipped product
  version and cover that alignment in the backup harness.

## [0.38.1] - 2026-09-03

### Changed

- Split import review rendering out of the main import controller so every
  handwritten source file remains within the enforced 600-line limit.

### Fixed

- Let a successful regenerated preview supersede historical diagnostics and
  invalid assembly manifests in the model problem center for the same source
  and conversion profile.
- Restored the main 3D viewer dimensions after closing a file-detail dialog by
  observing container resizes and scheduling a layout refresh after reparenting.
- Validate stored assembly manifests in the model problem center, reject
  duplicate occurrence IDs, and emit globally unique native converter node IDs.
- Prefer browser-supported STEP/IGES/BREP sources over proprietary CAD during
  import primary-source suggestion and allow a linked STEP file to be selected
  directly as the model primary source without replacing model metadata.

## [0.38.0] - 2026-08-30

### Added

- Added streamed, revision-bound file and directory extension for existing
  models, with file metadata editing, safe media previews, downloads, and
  validated slicer handoff.
- Added impact-planned unlink, quarantine, recovery, and purge workflows for
  models, files, authors, tags, and collections, with scoped confirmations and
  actor-aware history.
- Added deterministic generated thumbnails, explicit regeneration and preview
  lifecycle controls, camera-aware inspection lighting, assembly hierarchy,
  selection, visibility, isolate/reset, properties, and a bounded problem center.
- Added personal inspection preferences and readable, sectioned instance
  settings without weakening administrator-owned operational limits.

### Changed

- Redesigned model files, tags, authors, settings, histories, dialogs, and
  destructive-action views for readable responsive and keyboard use.
- Extended the native conversion contract with a bounded thumbnail raster and
  allowlisted assembly-definition properties while preserving source bytes.

### Security

- File and catalog mutations remain deny-by-default, revision checked,
  same-origin/CSRF protected, bounded, audited, and rollback safe.
- Assembly manifests, preview diagnostics, slicer URLs, uploads, metadata, bulk
  problem actions, and generated artifacts now fail closed on foreign, stale,
  malformed, oversized, or unsafe input.

## [0.37.0] - 2026-08-30

### Added

- Added an owned, persistent import lifecycle with bounded history, exact resume,
  rename, cancellation, expiry, cleanup, storage accounting, result links, and
  owner-managed retention, capacity, and upload-concurrency policies.
- Added hardened ZIP intake with signature and regular-file checks, traversal,
  Unicode/case-collision, nesting, expansion-ratio, size, count, depth, and time
  limits; extracted items enter the same hash-verified staging workflow.
- Added explicit create/update targeting with expected model revisions, license,
  primary source, raster thumbnail, author, tags, collections, and persistent
  per-item conflict resolution without re-uploading completed bytes.
- Added an hourly sandboxed native import-cleanup service/timer, health heartbeat,
  structured evidence, and sanitized support-bundle lifecycle summaries.

### Changed

- Import publication now locks and revalidates draft, library, model revision,
  paths, hashes, selections, and dedup decisions, rolls back physical changes on
  persistence failure, and returns committed results idempotently.
- Legacy ownerless active drafts migrate to visible expired history so no
  ambiguous unpublished intake is silently adopted.

### Security

- Import access is actor-scoped for editors and globally visible only to owners
  and administrators; unsafe methods retain CSRF/same-origin enforcement and
  exact draft-bound cancellation confirmation.
- Database constraints and a transition trigger enforce lifecycle states while
  API errors avoid filesystem paths, SQL details, and other host internals.

## [0.36.1] - 2026-08-30

### Fixed

## [0.36.0] - 2026-08-30

### Added

- Added revisioned post-import model maintenance for descriptive metadata,
  license, author, reusable tags and collections, primary CAD/mesh source, and
  presentation orientation with explicit conflict responses.
- Added complete standalone author, collection, and tag administration,
  including Unicode-normalized identity, provenance, membership management,
  retained aliases, scoped confirmations, merge deduplication, and pagination.
- Added explicit default/source/artifact thumbnail state, safe raster candidate
  derivation, shared card/detail/editor presentation, broken-source fallback,
  stable artifact streaming, and retention protection for selected artifacts.
- Added bounded model-scoped business history with actor snapshots, allowlisted
  changes, accessible pagination, and audit coverage for imports and catalog
  relationship changes.

### Changed

- Model, collection, tag, thumbnail, and component mutations now use durable
  revisions so concurrent changes fail visibly instead of overwriting state.
- Existing imports use the same normalized author/tag/collection identities as
  standalone maintenance and revalidate collection activity at commit time.

### Security

- Restricted standalone vocabulary administration to administrator/owner while
  preserving editor-only contextual catalog mutations and viewer read access.
- Raster thumbnail selection rejects SVG, missing or foreign sources, arbitrary
  paths/URLs, non-ready artifacts, and unsupported media; SVG sources are
  download-only and never rendered inline.
- Catalog history excludes confirmations, security/session evidence, request
  metadata, private paths, environment data, and whole-object snapshots.

## [0.35.0] - 2026-08-30

## [0.34.0] - 2026-08-29

### Added

- Added durable owner-/administrator-managed daily scan schedules with IANA
  time zones, deterministic daylight-saving transitions, missed-run
  coalescing, restart-safe PostgreSQL claiming, and visible next/last outcomes.
- Added validated scan and conversion concurrency settings enforced by
  serialized PostgreSQL claims and bounded native worker batches.
- Added persistent native conversion profiles with immutable per-job option
  snapshots and exact argument propagation to the guarded converter process.
- Added non-destructive retention previews and audited cleanup of rebuildable
  artifacts and aged diagnostics, plus native scheduler and retention timers
  with durable health heartbeats.

### Security

- Retention never targets originals or catalog history, rechecks terminal and
  reuse-protection state under row locks, and refuses symlinks or paths outside
  the canonical derived root.
- Profile, schedule, and cleanup mutations retain deny-by-default role, CSRF,
  same-origin, exact-confirmation, bounded-error, and actor-audit controls.

## [0.33.0] - 2026-08-29

### Added

- Added a protected, filterable central job view over durable scan and preview
  work with context, attempt lineage, timestamps, progress, safe diagnostics,
  and server-derived retry/cancel capabilities.
- Added row-locked, idempotent retry and cooperative cancellation transitions
  with exact confirmation text and actor-aware audit events committed atomically.
- Added native race tests proving queued and running cancellation preserve
  originals/catalog state and cannot be overwritten by worker completion.

### Security

- Job diagnostics are reduced to bounded operator summaries; raw converter,
  filesystem, command, environment, and database errors remain server-side.
- Job inventory and actions require owner/administrator capability plus existing
  CSRF and same-origin enforcement for mutations.

## [0.32.0] - 2026-08-29

### Added

- Added a protected operations-health API and Administration dashboard covering
  database/schema readiness, worker cadence, backup age, library storage, and
  recent scan outcomes under the shared operational-state model.
- Added durable, write-throttled success/failure heartbeats for preview and scan
  workers plus post-validation backup heartbeats.
- Added browser, OpenAPI, shell, and native PostgreSQL coverage for aggregate
  state, never-seen components, failures, and heartbeat throttling.

### Security

- The operations view is limited to owners and administrators and returns only
  bounded state, timestamps, counts, and stable reason codes—not journal output,
  environment values, database URLs, filesystem errors, or raw scan errors.

## [0.31.0] - 2026-08-29

### Added

- Added side-effect-free, two-second-bounded runtime storage probes for every
  managed library, including current reachability, directory type, effective
  read/write access, filesystem type, total/free bytes, and observation time.
- Added a shared `healthy`, `degraded`, and `blocked` operational state with
  stable reason codes and an accessible Administration presentation.
- Added native Linux and browser regressions for healthy, missing, regular-file,
  low-capacity, unknown-capacity, degraded, and blocked storage states.

### Changed

- New scan requests are refused when their library storage is currently
  unreachable, not a directory, unreadable, or below the one-GiB safety floor.
- Managed library responses and the OpenAPI contract now expose current storage
  evidence; ordinary catalog root responses remain path-redacted.

## [0.30.0] - 2026-08-29

### Added

- Completed the typed Phase 1 settings registry for instance identity, locale,
  time zone, session policy, import defaults, previews, thumbnails, enforced
  limits, and masked operator diagnostics.
- Added one-time user invitations, public activation, explicit account unlock,
  self-service password changes, and visible temporary-password/lock state.
- Added deterministic administration interaction tests and a native role matrix
  for viewer, editor, administrator, and owner boundaries.

### Changed

- Persisted session-duration settings now govern authentication dynamically,
  and import, preview, thumbnail, locale, and time-zone defaults are consumed by
  their owning workflows.
- Administrator-created passwords require replacement before the catalog or
  administrative APIs can be used.

### Security

- Invitation secrets are stored only as SHA-256 digests, expire after seven
  days, and can be redeemed exactly once.
- Browser mutations require both a valid CSRF token and an exact same-origin
  Host/scheme match; POST, PUT, PATCH, and DELETE denial is integration-tested.
- Password replacement revokes other sessions, repeated failed login locks the
  account, and access-state transitions emit actor-aware audit evidence.
