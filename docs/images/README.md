# README-Aufnahmen

Die drei SVG-Dateien in diesem Verzeichnis sind generierte Bildartefakte. Jede
enthält eine komprimierte Browseraufnahme als eingebettetes JPEG. Sie wurden mit
Microsoft Edge aus `apps/volund-web/tests/responsive-surface.html` bei
1.440 × 1.000 CSS-Pixeln und ausschließlich synthetischen Daten erzeugt.

Die Aufnahmen zeigen den aktuellen Quellstand 0.39.0 und dürfen neu erzeugt
werden, wenn sich die Oberfläche wesentlich ändert. Sie enthalten keine
Produktionsdaten, CAD-Dateien, Zugangsdaten oder internen Infrastrukturwerte.
Als generierte Medien fallen sie nicht unter die 600-Zeilen-Grenze für
handgeschriebene Dateien.
